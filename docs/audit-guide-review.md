# 감리대응 문서 가이드 기반 점검 및 보완

## 결론

기존 화면은 RFP부터 요구사항·설계·시험·회의/CR·GAP/조치의 연결과 가상/실제 결과 구분을 제공하지만, 두 가이드가 제시하는 단계별 서식·확인 근거에는 부분적으로만 대응했습니다. 문서 구조와 점검 기준을 보완했으며, **실제 계약·발주자 확인·검사기준 승인·정량목표·정식 감리 판정·시정조치 완료를 확인한 것은 아닙니다.**

## 원문 및 적용 기준

- 한국지능정보사회진흥원, `SW_사업자를_위한_정보시스템_감리준비_가이드(2023.2).pdf` (20 PDF 페이지). 본문 제목은 「SW 사업자를 위한 정보시스템 감리 준비 및 대응 가이드」.
- 한국지능정보사회진흥원, `지능정보기술_감리_실무가이드(2023.2).pdf` (132 PDF 페이지). 빅데이터·클라우드·정보시스템 운영 및 유지관리 영역.
- 출처의 PDF 파일 페이지는 1부터 계산한 뷰어 페이지이며, 한 PDF 페이지에 인쇄 쪽수 2개가 배치되는 판형을 고려해 인쇄 쪽수와 구분합니다.
- 원문 가이드는 권장 실무사례를 사업 특성·계약·방법론에 맞춰 조정하는 성격입니다(준비 가이드 PDF 5쪽). 현행 법령 해석이나 정식 준수 인증으로 사용하지 않습니다.
- 준비 가이드 판권의 가공·인용 안내에 따른 표기: 한국지능정보사회진흥원의 「공공정보화사업 단계별 사업관리 가이드」. 본 점검에서는 실제 제공 문서명과 PDF 페이지를 추가로 구분했습니다.
- 원문 PDF와 원문 페이지 이미지는 공개 서버로 배포하지 않고, 출처를 붙인 점검 요약·서식 보완만 반영했습니다.

## 추가 화면

사업별 `가이드 점검`: 출처·페이지·적용성·보완 전/후·필요 증빙을 갖춘 22개 점검 항목.

사업별 `필수점검·증빙대장`: 17개 증빙 범주. 금융 예시의 개별 실행 검증 자료만 일부 존재하며, 이것은 정식 감리 제출·발주자 검수 증명이 아닙니다.

사업별 `검사기준서`, `시정조치 결과서`: 금융 41개·부산대 58개 요구사항에 연결.

## 상태 구분과 남은 작업

1. 소프트웨어의 CRITICAL/HIGH는 자체 검증의 심각도입니다. 가이드의 개선유형(필수/협의/권고) 및 감리의 적합/부적합 판정과 동일시하지 않습니다.
2. 실행하지 않았거나 증빙이 없는 것은 미확인/미점검으로 남깁니다. 점검제외는 사유·결정·발주자 확인 없이 자동 부여하지 않습니다.
3. 조치중이면 방법·예정일이 필요하고, 반영불가이면 사유 및 발주자 확인 문서가 필요합니다. 실제 조치·재시험·확인 없이 완료 처리하지 않습니다.
4. 현재 검사 기준 문구 상당수는 구체 입력 fixture·기대값·허용 오차·정량 목표와 승인 근거가 미확정입니다. 가이드의 예시 수치(예: 응답시간)를 해당 사업의 합의 목표로 임의 적용하지 않았습니다.
5. 계약/기술협상/수행계획·WBS, 정식 개발보안 진단, DB 표준, 데이터/모델 검토, SLA/책임분담, 복구/이관, 정식 감리 판정 및 시정조치 결과의 실제 자료가 필요합니다.
6. 이 작업은 감리 문서 예시와 가이드 대응 구조 보완입니다. 기존 fd 음수 현금·HTTP500 결함을 수정하지 않았고 해결됐다고 표시하지 않았습니다.

## 검증

실제 브라우저로 22개 출처 기반 점검·17개 증빙 범주, 두 사업의 검사/시정 결과서, 기존 대비표·요구정의·RTM·CR·조치표 필드, CSV 열/행 정합성, 페이지 범위, 검색/정렬·모바일을 확인했습니다. 실제 결과표의 빨간 오류 셀과 RTM 드래그앤드롭도 회귀 검증했습니다.
