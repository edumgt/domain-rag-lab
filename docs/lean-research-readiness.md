# LEAN 연구 준비도 및 현실성 검증

2026-10-15 현재 기능 감사 및 보완.

## 적용된 기능

- 기존 예시 조건과 실제 종목·전략·기간·지표 준비 구간 대조 및 잘못된 데이터 실행 차단.
- 미국 입문 SPY / 한국 단일자산 연구 범위를 명시. 글로벌 혼합 자산배분 요청은 미지원 오류로 종료.
- 별도 종가 기반 연구 계산: 직전 봉까지 신호 판단 → 다음 봉 종가 체결.
- 수수료·슬리피지 편도 bp, 진입 목표 비중, 손절, 직전 종가와 추세 MA 비교 필터.
- 동일 기간 비용 전/후·위험관리 적용·동일 종목 보유 기준 비교와 실제 원시 종가 차트.
- 고정 파라미터 시간순 3구간과 주변 파라미터 0.8/1.0/1.2배 민감도. 최적화/OOS 인증은 아님.
- 모든 입력·적용 판정·원본 관측·성과·한계를 JSON 보고서로 다운로드.
- LEAN 로컬 실패 종료코드·명시적인 런타임 오류를 성공으로 표시하던 경로 차단. 원격 실행 비정상 종료도 오류로 처리.

## 아직 충족되지 않은 조건

- 기존 LEAN 공식 주문/체결 결과와 pandas/연구 통계의 대사는 미완료. 준비 구간·DCA 분배·체결 시점 등이 다를 수 있다.
- 새 연구 설정은 `/backtests/research`에만 적용. `/backtests/run`과 운영 전략 스펙에는 자동 적용하지 않는다.
- 연구 계산은 비용을 종가 체결 대금에 비례한 차감액으로 단순화한다. 실제 호가·유동성·시장충격 모델이 아니다.
- 손절은 직전 종가의 진입가 대비 하락을 다음 종가에 청산한다. 갭 손실 때문에 설정 손절률을 넘길 수 있다.
- 진입 목표 비중은 이후 가격 상승에 맞춰 계속 재조정하는 최대 비중 상한이 아니다.
- 현재 종목 선택에 따른 생존/선택편향, 기업행사, 총수익(배당), 환율, 세금, 상장폐지 유니버스는 미해결.
- KST 및 America/New_York 통화를 명시하되 이 일봉 연구가 장중 세션·DST·휴장 체결을 재현한다는 뜻은 아니다.
- RSI/MACD 전략·글로벌 다중자산은 미지원. SPY가 항상 적합하거나 개별주가 항상 불리하다는 판정을 하지 않는다.
- 연결된 기존 Walk-Forward 페이지는 가상 데이터의 개념 실습이며 현재 종목의 독립 OOS 검증이 아니다.

## 검증

- 비용 적용 시 동일 신호 순수익 저하, 목표 비중, 손절 갭, 미래 가격 변경에 대한 과거 결과 불변성(4개 전략), 시간순 분할, 범위·숫자 검증, 엔진 오류 차단 단위 테스트.
- 화면에서 설정 전달·원본 응답 렌더링·보고서 다운로드·조건 변경 무효화·미지원 범위 차단·모바일 검증.

- 최종 관련 Python 테스트 16개 통과. 실제 SPY 447거래일 연구 계산에서 비용 적용 전 23.21%, 비용 적용 후 19.45%를 확인했다(해당 실행의 가정 기준). 기존 삼성전자 LEAN 실행 정상 및 모바일·다운로드·글로벌 미지원 차단을 확인했다.
