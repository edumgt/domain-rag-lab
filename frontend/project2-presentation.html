프로젝트2 발표

프로젝트 발표용 준비사항을 확인하고, 주요 기능과 본인이 수행한 업무를 중심으로 발표를 준비하세요.

01. 주요 기능 동영상 준비

주요 기능 동영상을 3개 이상 준비합니다. 각 동영상은 3분 내외로 구성하여 주요 기능을 간결하게 시연합니다.

  • 동영상마다 다른 주요 기능을 선정하고, 기능의 목적 → 실행 과정 → 결과 순서로 보여줍니다.
  • 화면 녹화에 설명이나 자막을 넣어 어떤 기능인지 이해할 수 있게 준비합니다.
  • 발표자료에 동영상 링크 또는 파일을 연결하고, 발표 전에 재생 여부를 확인합니다.

구성 예시: 동영상 1 — 핵심 사용자 흐름 / 동영상 2 — 데이터 처리·분석 기능 / 동영상 3 — 결과 조회·활용 기능 (각 3분 내외)

3분 내외 시연 동영상 샘플

CampusX의 공개 프로젝트 소개·시연 영상입니다. 영상의 기능 소개와 화면 시연 구성을 참고해 본인 프로젝트의 동영상을 준비하세요.

02. 개발 시스템 공개 주소 준비

개발 시스템 데모 사이트 주소 또는 GitHub public 저장소 주소를 준비합니다.

  • 데모 사이트: 접속 가능한 URL과 시연 순서를 발표자료에 기재합니다. 로그인이 필요하면 시연용 계정과 이용 방법도 준비합니다.
  • GitHub: public 저장소 주소를 기재하고, README에 프로젝트 소개, 실행 방법, 주요 기능을 정리합니다.
  • 발표 전에 다른 브라우저에서도 링크가 열리는지 확인하고, 시연에 필요한 데이터를 준비합니다.

03. 팀원별 발표자료와 담당 업무 정리

팀 프로젝트의 경우 각자 발표자료를 준비하고, 본인 업무 위주로 발표합니다.

  • 팀 전체 프로젝트의 목적과 역할 분담을 간단히 소개합니다.
  • 각 팀원은 본인이 맡은 업무, 직접 구현한 기능, 개발 과정과 결과를 중심으로 발표합니다.
  • 본인 업무와 연결되는 화면·코드·동영상 등 구체적인 결과물을 제시합니다.
  • 해결한 문제, 개선한 내용, 남은 과제와 배운 점을 정리하고 팀원 간 발표 순서를 맞춥니다.

발표 전 최종 확인

  • 주요 기능 동영상 3개 이상 · 각 3분 내외 준비
  • 개발 시스템 데모 사이트 또는 GitHub public 주소 기재
  • 팀원 각자의 발표자료와 본인 담당 업무 정리
  • 동영상 재생, 공개 링크 접속, 시연 흐름 확인
