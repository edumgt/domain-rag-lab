화면 녹화 스크립트로 시연 동영상 만들기 — python-basic-lab

별도 녹화 프로그램 없이 Python 스크립트로 화면을 캡처해 mp4 동영상을 만드는 방법입니다. edumgt / python-basic-lab 저장소의 lab_video_capture/ 폴더에 두 가지 버전이 있습니다. 단축키로 녹화를 시작·종료하면 mss 가 화면을 프레임 단위로 캡처하고 OpenCV 가 mp4 로 저장합니다.

스크립트특징의존성결과 파일
screen_recorder.py
고급 버전		Ctrl+1 → 5초 뒤 녹화 시작 · 마우스 커서를 녹색 점으로 표시 · Ctrl+3 종료 시 마지막 5초 자동 제거(종료 단축키 누르는 장면이 영상에 남지 않음) · 24 fpsopencv-python mss pillow pynput pyautogui numpyz_YYYYMMDD_HHMMSS.mp4
screen_recorder_basic.py
기본 버전 + TTS		Ctrl+1 시작 · Ctrl+3 종료 후 gTTS 로 설명 음성을 합성하고 ffmpeg 로 영상에 입힘 · 15 fpsopencv-python mss pillow pynput gtts numpy + ffmpeg 실행 파일record_….mp4 → final_record_….mp4(음성 포함)

실행 순서

  1. 준비 — 저장소를 받고 가상환경에 의존성을 설치합니다. TTS 버전은 PATH 에 ffmpeg 가 있어야 합니다. 
    git clone https://github.com/edumgt/python-basic-lab.git
cd python-basic-lab
python -m venv .venv && .venv\Scripts\activate        # macOS/Linux: source .venv/bin/activate
pip install opencv-python mss pillow pynput pyautogui numpy gtts
  2. 실행 — 녹화할 화면(브라우저 데모 등)을 미리 띄운 뒤 터미널에서 스크립트를 켭니다. 
    python lab_video_capture/screen_recorder.py          # 커서 표시 · 자동 트림
python lab_video_capture/screen_recorder_basic.py    # TTS 설명 음성 합성
  3. 녹화 — Ctrl+1 시작(고급 버전은 5초 뒤) → 기능의 목적 → 실행 과정 → 결과 순서로 시연 → Ctrl+3 종료·저장. Ctrl+5 는 저장 없이 강제 종료입니다.
  4. 확인 — 스크립트를 실행한 폴더에 mp4 가 생깁니다. 재생해 보고, 자막이나 설명이 필요하면 아래 편집 랩으로 이어갑니다.

핵심 코드 — 화면 캡처가 동영상이 되는 과정

두 스크립트의 녹화 루프는 같은 구조입니다. 모니터를 캡처해 중앙을 잘라 해상도를 맞추고, BGR 로 바꿔 프레임을 모은 뒤 VideoWriter 로 씁니다.

sct = mss(); monitor = sct.monitors[1]                      # 주 모니터
while RECORDING:
    sct_img = sct.grab(monitor)                               # ① 화면 캡처 (raw 버퍼)
    img = Image.frombytes("RGB", sct_img.size, sct_img.rgb)   # ② PIL 이미지로
    img = img.crop(center_crop(sct_img.width, sct_img.height, RESOLUTION)).resize(RESOLUTION)  # ③ 중앙 크롭 · 리사이즈
    frame = cv2.cvtColor(np.array(img), cv2.COLOR_RGB2BGR)   # ④ OpenCV 색순서(BGR)
    frames.append(frame)                                      # ⑤ 프레임 누적
    time.sleep(1 / FPS)

out = cv2.VideoWriter(VIDEO_NAME, cv2.VideoWriter_fourcc(*"mp4v"), FPS, RESOLUTION)
for f in frames: out.write(f)                                 # ⑥ mp4 로 저장
out.release()

3분 내외 시연 영상에 맞게 고칠 점

  • 해상도를 가로형으로 — 기본값 RESOLUTION = (768, 1366)(고급) · (720, 1080)(기본)은 세로형입니다. 브라우저 시연이면 RESOLUTION = (1280, 720) 처럼 가로형으로 바꾸고, 모니터 해상도보다 작아야 중앙 크롭이 됩니다.
  • 메모리 주의 — 두 스크립트는 프레임을 메모리에 모았다가 저장합니다. 768×1366 · 24 fps 로 3분을 찍으면 약 4,320 프레임 × 3 MB ≈ 13 GB 가 필요합니다. 3분 영상은 FPS = 10 정도로 낮추거나, 아래처럼 루프 안에서 바로 파일에 쓰도록 바꾸세요. 
    out = cv2.VideoWriter(VIDEO_NAME, cv2.VideoWriter_fourcc(*"mp4v"), FPS, RESOLUTION)   # 녹화 시작 때 열고
while RECORDING:
    ...                       # 캡처·크롭·BGR 변환은 그대로
    out.write(frame)          # frames.append 대신 바로 기록 → 메모리 사용량 일정
out.release()
  • TTS 설명 문구 — 기본 버전의 description 문자열이 그대로 음성이 됩니다. "이 영상은 … 기능을 시연합니다. 먼저 … 다음 … 결과는 …" 처럼 영상 구성에 맞춰 바꾸세요. 음성이 영상보다 짧으면 -shortest 때문에 영상이 잘리니, 길이를 맞추거나 그 옵션을 빼세요.
  • 단축키가 안 먹을 때 — macOS 는 터미널에 손쉬운 사용(입력 모니터링) 권한을, Linux Wayland 는 X11 세션을 써야 pynput 전역 단축키와 mss 캡처가 동작합니다. Windows 는 그대로 됩니다.
  • 이어서 편집 — 같은 저장소의 lab_video_edit/(클립 자르기·이어 붙이기), lab_video_analysis/video_captioner.py(자막) 로 녹화본에 자막·구간 편집을 더할 수 있습니다.

03. 팀원별 발표자료와 담당 업무 정리

팀 프로젝트의 경우 각자 발표자료를 준비하고, 본인 업무 위주로 발표합니다.

  • 본인 소개: 이름, 관심 분야, 보유 기술과 강점을 간단히 소개합니다.
  • 지향하는 취업 또는 창업의 방향: 취업을 희망하는 직무·산업 분야 또는 창업하고 싶은 서비스·해결할 문제를 설명합니다. 이번 프로젝트에서 쌓은 경험과 앞으로의 준비 계획을 연결해 발표합니다.
  • 팀 전체 프로젝트의 목적과 역할 분담을 간단히 소개합니다.
  • 각 팀원은 본인이 맡은 업무, 직접 구현한 기능, 개발 과정과 결과를 중심으로 발표합니다.
  • 본인 업무와 연결되는 화면·코드·동영상 등 구체적인 결과물을 제시합니다.
  • 해결한 문제, 개선한 내용, 남은 과제와 배운 점을 정리하고 팀원 간 발표 순서를 맞춥니다.

04. 질의응답

질의자는 공격적으로, 답변자는 적극적으로 모의 인터뷰 스타일로 진행합니다.

  • 질의자: 프로젝트의 기획 의도, 기술 선택, 구현 방식과 결과를 날카롭게 질문하고, 답변에 따라 구체적인 근거를 묻는 후속 질문을 이어갑니다.
  • 답변자: 본인이 수행한 업무와 결과를 중심으로 적극적으로 답변하고, 실제 코드·화면·시연 결과를 근거로 설명합니다.
  • 진행 방식: 질문 → 답변 → 후속 질문 순서로 모의 인터뷰를 진행합니다. 모르는 내용은 솔직하게 인정하고 확인 방법이나 개선 계획을 제시합니다.

질문 예시: “왜 이 기술을 선택했나요?”, “본인이 직접 구현한 부분은 어디인가요?”, “기능이 실패하면 어떻게 대응하나요?”, “이 경험이 희망하는 취업 또는 창업 방향과 어떻게 연결되나요?”
