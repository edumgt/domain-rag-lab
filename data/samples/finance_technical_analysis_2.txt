### 1. 캔들 패턴 분석 (도지, 망치, 장악형 등)

> 📖 **Wikipedia**: [캔들스틱 차트](https://ko.wikipedia.org/wiki/캔들스틱_차트)

캔들 차트 하나(봉)는 시가·고가·저가·종가를 한눈에 보여줍니다. 캔들의 몸통 크기와 꼬리 길이가 그날의 매수·매도 심리를 나타냅니다.

**캔들의 구조**

```mermaid
block-beta
  columns 1
  H["🔺 고가 (High)\n위 꼬리 / 윗 그림자"]
  O["📦 시가 (Open)\n음봉: 시가 > 종가 → 하락 (빨간/회색)"]
  C["📦 종가 (Close)\n양봉: 시가 < 종가 → 상승 (파란/흰색)"]
  L["🔻 저가 (Low)\n아래 꼬리 / 아랫 그림자"]

  H --> O
  O --> C
  C --> L
```


**OHLC 관계도**

```mermaid
flowchart TD
    H(["고가 High"]):::high
    O(["시가 Open"]):::open
    C(["종가 Close"]):::close
    L(["저가 Low"]):::low

    H -->|"위 꼬리"| O
    O -->|"몸통 (음봉: O > C)"| C
    C -->|"아래 꼬리"| L

    classDef high fill:#ff6b6b,color:#fff,stroke:#c0392b
    classDef open fill:#f39c12,color:#fff,stroke:#d35400
    classDef close fill:#3498db,color:#fff,stroke:#2980b9
    classDef low fill:#2ecc71,color:#fff,stroke:#27ae60
```

**주요 캔들 패턴**

| 패턴 | 모양 특징 | 의미 |
|------|-----------|------|
| **도지(Doji)** | 몸통이 거의 없음 (시가≈종가) | 매수·매도 균형, 방향 전환 가능성 |
| **망치(Hammer)** | 짧은 몸통 + 긴 아래 꼬리 (하락 후 나타남) | 매도세가 결국 매수세에 밀림 → 반등 신호 |
| **역망치(Inverted Hammer)** | 짧은 몸통 + 긴 위 꼬리 (하락 후 나타남) | 매수 시도 후 저항, 반등 가능성 |
| **교수형(Hanging Man)** | 망치와 모양 같지만 상승 후 나타남 | 상승 추세 마감 신호 |
| **불리쉬 엔걸핑(Bullish Engulfing)** | 큰 양봉이 앞날 음봉 전체를 덮음 | 강한 매수 전환 신호 |
| **베어리쉬 엔걸핑(Bearish Engulfing)** | 큰 음봉이 앞날 양봉 전체를 덮음 | 강한 매도 전환 신호 |
| **샛별(Morning Star)** | 음봉 → 도지 → 양봉 3캔들 조합 | 바닥 반전 강한 신호 |


**캔들 패턴 실전 활용 — 패턴만으로 매매하면 안 되는 이유**

| 체크 항목 | 이유 |
|-----------|------|
| 패턴 발생 위치 (지지선·저항선 근처인가?) | 위치가 맞아야 신뢰도 상승 |
| 거래량이 평균보다 많은가? | 거래량 동반 시 신호 강도 증가 |
| 다음 봉이 방향을 확인해주는가? | 확인봉 없이 단독 진입은 위험 |
| 추세 방향과 일치하는가? | 추세 역방향 패턴은 성공률 낮음 |

**실전 신뢰도 판단 흐름**

```mermaid
flowchart TD
    A([캔들 패턴 발견]) --> B{지지·저항선\n근처인가?}
    B -- 아니오 --> Z1([신뢰도 낮음 → 관망])
    B -- 예 --> C{거래량\n평균 초과?}
    C -- 아니오 --> Z2([신호 약함 → 소규모 진입])
    C -- 예 --> D{다음 봉이\n방향 확인?}
    D -- 아니오 --> Z3([확인봉 대기])
    D -- 예 --> E{추세 방향\n일치?}
    E -- 아니오 --> Z4([역추세 패턴 → 신중])
    E -- 예 --> F([✅ 4조건 충족 → 높은 신뢰도 매수·매도 신호])

    style A fill:#34495e,color:#fff
    style F fill:#27ae60,color:#fff
    style Z1 fill:#c0392b,color:#fff
    style Z2 fill:#e67e22,color:#fff
    style Z3 fill:#f39c12,color:#fff
    style Z4 fill:#8e44ad,color:#fff
```

### 2. 차트 패턴 분석 (헤드앤숄더, 이중천장 등)

> 📖 **Wikipedia**: [기술적 분석](https://ko.wikipedia.org/wiki/기술적_분석_(금융)) · [머리어깨형](https://ko.wikipedia.org/wiki/머리어깨형)

차트 패턴은 여러 캔들에 걸쳐 형성되는 **가격 흐름의 모양**으로, 추세 전환이나 지속을 예측하는 데 활용합니다.


**반전 패턴 (Reversal Patterns)**

| 패턴 | 모양 | 신호 |
|------|------|------|
| **헤드앤숄더(H&S)** | 세 봉우리 (중간이 가장 높음) | 상승 추세 종료, 하락 전환 |
| **역 헤드앤숄더** | 세 골짜기 (중간이 가장 낮음) | 하락 추세 종료, 상승 전환 |
| **이중천장(Double Top)** | M자 모양 (두 개의 비슷한 고점) | 강한 저항, 하락 전환 |
| **이중바닥(Double Bottom)** | W자 모양 (두 개의 비슷한 저점) | 강한 지지, 상승 전환 |

**헤드앤숄더 패턴 구조**

```mermaid
xychart-beta
    title "헤드앤숄더 (Head & Shoulders) 패턴"
    x-axis ["t1", "LS고점", "t3", "Head고점", "t5", "RS고점", "t7", "넥라인 이탈", "t9"]
    y-axis "가격" 90 --> 160
    line [100, 130, 115, 155, 120, 132, 108, 95, 85]
```

```mermaid
flowchart LR
    subgraph HnS["헤드앤숄더 형성 과정"]
        direction LR
        LS["왼쪽 어깨\n(Left Shoulder)\n1차 고점"]
        H["머리 (Head)\n2차 고점\n가장 높음"]
        RS["오른쪽 어깨\n(Right Shoulder)\n3차 고점\n머리보다 낮음"]
        NL["넥라인\n(Neckline)\n두 골짜기 연결"]
        BD["넥라인 하향 이탈\n↓ 매도 신호 확정"]
        TP["목표가 계산\n= 넥라인 - (머리 - 넥라인)"]
    end

    LS --> H --> RS --> NL --> BD --> TP

    style LS fill:#3498db,color:#fff
    style H fill:#e74c3c,color:#fff
    style RS fill:#3498db,color:#fff
    style NL fill:#f39c12,color:#fff
    style BD fill:#c0392b,color:#fff
    style TP fill:#8e44ad,color:#fff
```


**지속 패턴 (Continuation Patterns)**

| 패턴 | 의미 |
|------|------|
| **삼각수렴(Triangle)** | 변동성 축소 후 기존 방향으로 돌파 |
| **깃발(Flag)** | 급등/급락 후 잠시 쉬고 같은 방향 지속 |
| **페넌트(Pennant)** | 깃발과 유사하나 삼각 수렴 형태 |

**차트 패턴 실전 목표가 계산법**

```mermaid
flowchart TD
    A([패턴 확인]) --> B{패턴 유형?}

    B -->|헤드앤숄더| C["목표가 (하락)\n= 넥라인 - (헤드 고점 - 넥라인)"]
    B -->|이중천장| D["목표가 (하락)\n= 넥라인 - (천장 고점 - 넥라인)"]
    B -->|이중바닥| E["목표가 (상승)\n= 넥라인 + (넥라인 - 바닥 저점)"]
    B -->|삼각수렴| F["목표가\n= 돌파점 ± 삼각형 최대 높이"]

    C --> G([포지션 설정 & 손절선 결정])
    D --> G
    E --> G
    F --> G

    style A fill:#2c3e50,color:#fff
    style G fill:#27ae60,color:#fff
    style C fill:#e74c3c,color:#fff
    style D fill:#e74c3c,color:#fff
    style E fill:#3498db,color:#fff
    style F fill:#9b59b6,color:#fff
```

**패턴 신뢰도 높이는 조건**

| 조건 | 효과 |
|------|------|
| 패턴 형성에 시간이 오래 걸릴수록 | 돌파 후 움직임이 크고 신뢰도 높음 |
| 돌파 시 거래량 급증 | 돌파의 진정성 확인 |
| 넥라인 돌파 후 눌림목에서 지지 확인 | 재진입 기회이자 패턴 확정 |
| 여러 시간대(일봉·주봉)에서 동시 형성 | 더 강한 신호 |

### 3. 엘리어트 파동 이론 (Elliott Wave Theory)

> 📖 **Wikipedia**: [엘리엇 파동 이론](https://ko.wikipedia.org/wiki/엘리엇_파동_이론) · [피보나치 수열](https://ko.wikipedia.org/wiki/피보나치_수열)

랄프 넬슨 엘리어트(Ralph Nelson Elliott)가 1930년대에 제안한 이론으로, 주가가 **군중 심리의 반복 패턴**에 따라 파동 형태로 움직인다고 봅니다.


---

#### 3-1. 기본 파동 구조 — 충격 5파 + 조정 3파

상승 추세에서는 **5개의 충격파(임펄스)**와 **3개의 조정파(a-b-c)**가 한 사이클을 이룹니다.

**엘리어트 기본 8파동 구조**

```mermaid
xychart-beta
    title "엘리어트 파동 기본 구조 (충격 5파 + 조정 a-b-c)"
    x-axis ["시작", "1파↑", "2파↓", "3파↑", "4파↓", "5파↑", "a파↓", "b파↑", "c파↓"]
    y-axis "가격 (상대)" 60 --> 160
    line [80, 110, 95, 145, 130, 155, 130, 142, 108]
```

| 파동 구분 | 파동 | 방향 | 군중 심리 |
|-----------|------|------|-----------|
| 충격파(추세) | **1파** | 상승 | 소수만 인식, "반등 아닐까?" |
| 충격파(추세) | **2파** | 하락 | "역시 하락이었어" 공포 매도 |
| 충격파(추세) | **3파** | 강상승 | "진짜 상승이다!" 추세 추종 |
| 충격파(추세) | **4파** | 하락 | 이익 실현, 단기 조정 |
| 충격파(추세) | **5파** | 약상승 | "아직 올라!" 뒤늦은 매수 |
| 조정파(역추세) | **a파** | 하락 | "잠깐 조정이겠지" 낙관 |
| 조정파(역추세) | **b파** | 상승 | "역시 오르네" 반등 매수 |
| 조정파(역추세) | **c파** | 강하락 | 패닉셀, 손절 쏟아짐 |

#### 3-2. 절대 불변 규칙 3가지

> 이 규칙 중 하나라도 어기면 파동 카운팅을 전부 재시작해야 합니다.

```mermaid
flowchart TD
    R1["규칙 1\n2파는 1파의 시작점 이하로\n내려가면 안 된다\n(0% 이하 이탈 = 카운팅 무효)"]
    R2["규칙 2\n3파는 5개 충격파 중\n가장 짧은 파동이 되면 안 된다\n(1파·5파 중 하나보다 반드시 길어야)"]
    R3["규칙 3\n4파는 1파의 가격 영역과\n겹치면 안 된다\n(4파 저점 < 1파 고점 → 무효)"]

    CHECK{규칙 위반 발생?}
    VALID([카운팅 유효 → 분석 계속])
    RESET([카운팅 전면 재시작])

    R1 --> CHECK
    R2 --> CHECK
    R3 --> CHECK
    CHECK -->|"모두 준수"| VALID
    CHECK -->|"하나라도 위반"| RESET

    style R1 fill:#e74c3c,color:#fff
    style R2 fill:#e74c3c,color:#fff
    style R3 fill:#e74c3c,color:#fff
    style VALID fill:#27ae60,color:#fff
    style RESET fill:#c0392b,color:#fff
```

#### 3-3. 피보나치 비율과 각 파동의 관계

엘리어트 파동이론과 피보나치 수열은 분리할 수 없습니다. 각 파동의 크기는 피보나치 비율을 따르는 경향이 있습니다.

| 파동 | 일반적 피보나치 목표 | 설명 |
|------|---------------------|------|
| **2파** (1파 되돌림) | 0.618 × 1파 크기 | 1파 상승분의 61.8% 되돌림 구간 진입 대기 |
| **3파** (1파 대비 연장) | 1.618 × 1파 크기 | 3파 목표가 = 1파 시작 + (1파 크기 × 1.618) |
| **4파** (3파 되돌림) | 0.382 × 3파 크기 | 3파 상승분의 38.2% 되돌림 (얕은 조정) |
| **5파** (1파와 동일하거나 더 짧음) | 0.618 × 3파 또는 1파와 동일 | 3파 대비 짧게 끝나면 종료 임박 신호 |
| **a파** (5파 되돌림) | 0.382~0.618 × 5파 크기 | a파 크기로 c파 목표 예측 |
| **c파** (a파 연장) | a파 크기와 동일하거나 1.618배 | c파 = a파 시작 - (a파 크기 × 1.0~1.618) |

**실전 예시 (코스피 2020~2022 가상 적용)**

```
2020.03 코스피 1,457 (바닥) → 1파 시작
2020.06 코스피 2,200 → 1파 완성 (+51%)
2020.09 코스피 1,900 → 2파 완성 (1파의 40% 되돌림 ≈ 피보나치 38.2%)
2021.01 코스피 3,266 → 3파 완성 (1파의 2.7배 ≈ 피보나치 261.8%)
2021.05 코스피 2,890 → 4파 완성 (3파의 20% 되돌림)
2021.07 코스피 3,305 → 5파 완성 (새 고점, 거래량 3파 대비 감소)
2022.09 코스피 2,155 → a-b-c 조정 완성
```

#### 3-4. 조정파동의 3가지 유형

5파 상승 후 나타나는 a-b-c 조정은 모두 같은 형태가 아닙니다. 3가지 주요 유형이 있습니다.

**유형 1: 지그재그(Zigzag) — 5-3-5 구조**

```mermaid
xychart-beta
    title "지그재그 조정 (Zigzag: 5-3-5 구조)"
    x-axis ["5파 고점", "a1", "a2", "a3", "a4", "a저점(b시작)", "b반등", "b고점", "c시작", "c1", "c2", "c3", "c저점"]
    y-axis "가격" 60 --> 110
    line [105, 98, 102, 92, 96, 85, 90, 93, 88, 82, 78, 75, 70]
```

- 가장 흔한 조정 패턴
- c파가 a파 저점 아래로 하락 → 큰 되돌림
- 2파에서 자주 나타남

**유형 2: 플랫(Flat) — 3-3-5 구조**

```mermaid
xychart-beta
    title "플랫 조정 (Flat: 3-3-5 구조)"
    x-axis ["5파 고점", "a1", "a저점", "b반등1", "b고점(5파근처)", "c시작", "c1", "c2", "c저점(a저점근처)"]
    y-axis "가격" 75 --> 110
    line [105, 98, 93, 100, 104, 99, 92, 88, 86]
```

- 조정 폭이 얕아 강세장 신호
- 4파에서 자주 나타남

**유형 3: 삼각형(Triangle) — 3-3-3-3-3 구조**

```mermaid
xychart-beta
    title "삼각형 조정 (Triangle: 3-3-3-3-3 수렴)"
    x-axis ["시작", "a고점", "a저점", "b고점", "b저점", "c고점", "c저점", "d고점", "d저점", "e고점", "돌파"]
    y-axis "가격" 80 --> 120
    line [100, 115, 88, 110, 91, 106, 93, 103, 95, 100, 118]
```

- 변동성이 점점 줄어드는 패턴
- 4파 또는 b파에서 나타남
- 삼각형 돌파 방향이 다음 추세 방향

| 유형 | 구조 | c파 위치 | 발생 위치 | 함의 |
|------|------|----------|-----------|------|
| 지그재그 | 5-3-5 | a파 저점 아래 | 주로 2파 | 큰 조정, 매수 기회 낮음 |
| 플랫 | 3-3-5 | a파 저점 근처 | 주로 4파 | 얕은 조정, 추세 강건 |
| 삼각형 | 3-3-3-3-3 | 수렴 후 돌파 | 4파·b파 | 돌파 전 에너지 축적 |

#### 3-5. 파동의 프랙탈 구조 (파동 속 파동)

엘리어트 파동의 핵심 특성은 **자기 유사성(프랙탈)**입니다. 큰 파동 하나가 작은 파동들의 집합입니다.

```mermaid
flowchart TD
    GS["Grand Supercycle\n수십 년 단위"]
    SC["Supercycle\n수년 단위"]
    CY["Cycle\n연 단위"]
    PR["Primary\n월 단위"]
    IT["Intermediate\n주 단위"]
    MN["Minor\n일봉"]
    MT["Minute\n분봉"]
    NT["Minuette\n틱/초 단위"]

    GS --> SC --> CY --> PR --> IT --> MN --> MT --> NT

    style GS fill:#1a252f,color:#fff
    style SC fill:#2c3e50,color:#fff
    style CY fill:#34495e,color:#fff
    style PR fill:#2980b9,color:#fff
    style IT fill:#3498db,color:#fff
    style MN fill:#5dade2,color:#fff
    style MT fill:#85c1e9,color:#000
    style NT fill:#aed6f1,color:#000
```

**실전 의미**: 일봉에서 보이는 5파 구조 전체가, 주봉으로 보면 단 하나의 3파일 수 있습니다.
→ 분석 시 **시간대를 여러 개 겹쳐 보는 것**이 중요합니다.

#### 3-6. 파동별 실전 매매 전략

| 파동 위치 | 가능한 전략 | 진입 조건 | 손절 기준 |
|-----------|------------|-----------|-----------|
| **2파 완성** | 3파 시작 예상 매수 | RSI 과매도 + 피보나치 61.8% 지지 + 거래량 반등 | 1파 시작점 이탈 시 |
| **3파 진행 중** | 추세 추종 매수 | 이전 고점 돌파 + 거래량 급증 + 정배열 | 4파 시작 조짐(다이버전스) 시 |
| **4파 완성** | 5파 예상 진입 (소형 포지션) | 피보나치 38.2% 지지 + 지지선 반등 확인 | 1파 고점 하향 이탈 시 |
| **5파 말단** | 포지션 축소 / 매도 준비 | RSI 다이버전스 + 거래량 감소 + 피보나치 확장 161.8% | 새로운 고점 형성 시 재검토 |
| **c파 완성** | 새 1파 매수 | 이전 저항선 돌파 + 거래량 회복 + MACD 골든크로스 | c파 저점 이탈 시 |

#### 3-8. 거래량으로 파동 확인하기

| 파동 | 기대되는 거래량 패턴 | 이유 |
|------|---------------------|------|
| 1파 | 평균 이상, 상승 시 | 소수가 먼저 매수 |
| 2파 | 1파보다 감소 | 공포 매도 후 소강 |
| **3파** | **폭발적 증가 (가장 많음)** | 추세 추종 + 뉴스 + 기관 매수 |
| 4파 | 3파보다 감소 | 이익 실현, 관망 |
| 5파 | 3파보다 적음 | 뒤늦은 개인 매수, 기관 매도 |
| a파 | 갑자기 증가 | 예상 못한 하락 |
| b파 | 감소 | 반등이지만 신뢰도 낮음 |
| c파 | 증가 (패닉셀) | 손절물량 + 공매도 |

#### 3-9. 실전 조합 전략 — 피보나치·보조지표 연동

```
[최강 매수 조건 — 3파 진입]
  엘리어트 2파 저점 근처
  + 피보나치 61.8% 되돌림 지지
  + RSI < 30 (과매도)
  + MACD 히스토그램 반전 (음→양)
  + 거래량 바닥 후 반등
  → 3파 상승 진입 조건 충족 → 강한 매수 신호

[최강 매도 조건 — 5파 청산]
  엘리어트 5파 고점 근처
  + 피보나치 확장 161.8% 도달
  + RSI 70 이상 + 다이버전스 발생
  + MACD 하락 전환 조짐
  + 거래량 5파가 3파보다 적음
  → a파 시작 경고 → 매도 또는 이익 실현 신호

[조정 완료 확인 — c파 바닥 매수]
  a파·c파 크기 동일 (or c파 = a파 × 1.618)
  + 피보나치 61.8~78.6% 되돌림 지지
  + 캔들 망치봉·역망치봉
  + 거래량 급감 후 반등
  → 새로운 1파 시작 가능성
```

#### 3-10. 주의사항 및 한계

| 항목 | 내용 |
|------|------|
| **주관성** | 파동 카운팅은 전문가마다 다를 수 있어 '정답'이 없음 |
| **후행성** | 파동이 완성돼야 확인 가능 — "지나야 보임" 비판 |
| **단독 사용 금지** | RSI·MACD·피보나치·거래량과 반드시 병행 |
| **시간대 선택** | 분봉·일봉·주봉 시간대에 따라 카운팅 결과가 달라짐 |
| **실패 확률** | 5파 이후 반드시 조정이 오지만 시점 예측은 불확실 |

### 4. 실습: 종목 선정 후 기본적·기술적 분석 통합 리포트

> 실제 증권사·자산운용사·투자은행에서 사용하는 **주식 리서치 리포트(Equity Research Report)** 수준의 통합 분석 리포트를 작성하는 전 과정을 단계별로 안내합니다.

---

#### 4-1. 통합 리포트란 무엇인가?

기본적 분석(Fundamental Analysis)과 기술적 분석(Technical Analysis)은 각각 단독으로는 한계가 있습니다.

| 구분 | 기본적 분석 | 기술적 분석 |
|------|------------|------------|
| **핵심 질문** | "이 기업이 싼가, 비싼가?" | "지금이 사야 할 때인가?" |
| **주요 도구** | PER, PBR, DCF, EV/EBITDA | MA, RSI, MACD, 볼린저밴드, 파동 |
| **시간 지평** | 중·장기 (6개월~수년) | 단·중기 (수일~수개월) |
| **한계** | 매수 타이밍을 알 수 없음 | 기업 내재가치를 알 수 없음 |

**통합 리포트**는 두 분석을 결합해 "좋은 기업을 좋은 가격과 좋은 타이밍에 사는" 의사결정 체계를 만듭니다.

```mermaid
flowchart LR
    FA["기본적 분석\n(Fundamental)\n내재가치 산출\n저평가 여부 확인"]
    TA["기술적 분석\n(Technical)\n차트 신호 확인\n진입 타이밍 포착"]
    INT["통합 판단\n(Integrated)\nBull / Bear / Neutral\n투자의견 + 목표주가"]

    FA -->|"밸류에이션 점수"| INT
    TA -->|"기술적 신호 점수"| INT
    INT -->|"최종 투자의견"| DECISION["매수 / 관망 / 매도\n+ 목표주가\n+ 손절가"]

    style FA fill:#2980b9,color:#fff
    style TA fill:#8e44ad,color:#fff
    style INT fill:#27ae60,color:#fff
    style DECISION fill:#1a252f,color:#fff
```

#### 4-2. Step 1 — 종목 선정 (스크리닝)

**종목 선정 3단계 깔때기(Funnel)**

```mermaid
    F1["1차 스크리닝 — 정량 필터\n시가총액 ≥ 1조 원 이상\n최근 3년 영업이익 흑자\n부채비율 ≤ 200%\nPER 0 < x ≤ 업종 평균 × 1.5"]
```

#### 4-4. Step 3 — 기술적 분석 섹션 작성

기본적 분석으로 종목이 선정되면, 기술적 분석으로 **진입 타이밍**과 **손절/목표가**를 설정합니다.

**기술적 분석 체크리스트 (7항목)**

| 번호 | 체크 항목 | 강세 신호 (Bullish) | 약세 신호 (Bearish) |
|------|----------|-------------------|-------------------|
| ① | **추세** | MA20 > MA60 정배열 | MA20 < MA60 역배열 |
| ② | **RSI** | 30~50 구간 (과매도 회복) | 70 이상 (과매수) |
| ③ | **MACD** | 골든크로스 + 히스토그램 양전환 | 데드크로스 + 히스토그램 음전환 |
| ④ | **볼린저밴드** | 하단 터치 후 반등 | 상단 터치 후 반락 |
| ⑤ | **거래량** | 상승 시 거래량 증가 | 상승 시 거래량 감소 |
| ⑥ | **캔들 패턴** | 망치봉·불리쉬 엔걸핑·샛별 | 교수형·베어리쉬 엔걸핑·저녁별 |
| ⑦ | **차트 패턴** | 이중바닥·역H&S 돌파 | 이중천장·H&S 넥라인 이탈 |

#### 4-5. Step 4 — 통합 판단 프레임워크 (스코어링)

기본적 분석과 기술적 분석 결과를 합산해 **투자의견**과 **목표주가 밴드**를 산출합니다.

| 항목 | 평가 기준 | 만점 | 가중치 |

```javascript
// technicalChart.js — Tab 7 종합리포트 스코어링
function calcSignalScore(prices, volumes) {
    let score = 0;
    const n = prices.length;

    const rsi    = calcRSI(prices, 14);
    const bb     = calcBB(prices, 20, 2);      // {mid, upper, lower}
    const macdObj = calcMACD(prices);           // {macd, signal, hist}
    const ma20   = calcMA(prices, 20);
    const ma60   = calcMA(prices, 60);
    const vol20  = calcMA(volumes, 20);         // 거래량 20일 평균

    const latestRSI    = rsi[n - 1];
    const latestPrice  = prices[n - 1];
    const latestMACD   = macdObj.macd[n - 1];
    const latestSignal = macdObj.signal[n - 1];
    const latestBBlow  = bb.lower[n - 1];
    const latestVol    = volumes[n - 1];
    const latestVol20  = vol20[n - 1];
    const latestMA20   = ma20[n - 1];
    const latestMA60   = ma60[n - 1];

    // 신호 1: RSI 과매도 (+2점)
    if (latestRSI < 30) score += 2;

    // 신호 2: MACD 골든크로스 (+2점)
    if (latestMACD > latestSignal) score += 2;

    // 신호 3: 볼린저밴드 하단 터치 (+1점)
    if (latestPrice <= latestBBlow) score += 1;

    // 신호 4: 거래량 20일 평균 초과 (+1점)
    if (latestVol > latestVol20) score += 1;

    // 신호 5: 단기MA > 장기MA 정배열 (+1점)
    if (latestMA20 > latestMA60) score += 1;

    // 판정
    if (score >= 5) return { score, verdict: "BUY" };
    if (score >= 3) return { score, verdict: "HOLD" };
    return { score, verdict: "SELL" };
}
```

# [주식 상식] 주식 종목 이름 뒤에 붙는 '우'의 의미와 차이점

주식 시장에서 같은 기업 이름 뒤에 **'우'**가 붙은 종목을 자주 볼 수 있습니다. (예: 삼성전자와 삼성전자우, 현대차와 현대차우) 

여기서 **'우'**는 **'우선주(Preferred Stock)'**를 뜻하며, '우'가 붙지 않은 주식은 **'보통주(Common Stock)'**라고 부릅니다. 두 주식의 핵심적인 차이점과 특징을 정리해 드립니다.

---

## 1. 핵심 차이점 3가지

### ① 의결권 (주주총회 투표권)
* **보통주:** 주주총회에 참석하여 회사의 주요 경영 사항에 대해 찬반 투표를 할 수 있는 **의결권이 있습니다.**
* **우선주:** 회사의 경영 참여를 위한 **의결권이 없습니다.** 대신 경제적인 이득을 우선적으로 챙기는 주식입니다.

### ② 배당금 (이익 분배)
* **보통주:** 우선주에 비해 배당 순위가 밀리며, 배당률도 상대적으로 낮습니다.
* **우선주:** 의결권을 포기한 대가로, 보통주보다 **배당금을 더 많이, 그리고 먼저(우선적으로)** 받습니다. (통상 액면가의 1% 내외를 더 지급)

### ③ 주가 및 거래량
* **보통주:** 시장의 대표 가격을 형성하며, 발행 주식 수가 많아 거래가 활발합니다.
* **우선주:** 보통주보다 주가가 **10~20% 정도 저렴하게** 형성되는 것이 일반적입니다. 다만, 발행 주식 수가 적어 사고팔 때 거래량이 부족할 수 있습니다.

---

## 2. 보통주 vs 우선주 한눈에 보기

| 구분 | 보통주 (예: 삼성전자) | 우선주 (예: 삼성전자우) |
| :--- | :--- | :--- |
| **의결권 (투표권)** | **있음** | **없음** |
| **배당금 지급** | 기준 배당 | **더 많이, 우선적으로 지급** |
| **주식 가격** | 상대적으로 비쌈 | 보통주 대비 10~20% 저렴함 |
| **거래량** | 많음 (원활한 매매 가능) | 상대적으로 적음 |
| **주요 투자 목적** | 시세 차익, 경영권 참여 | **안정적인 고배당 수익** |

---

## 3. 알면 유용한 추가 팁

### 💡 종목 뒤에 '우B'는 무엇인가요? (예: 현대차2우B)
* **숫자 (2, 3 등):** 발행된 순서를 의미합니다. (두 번째로 발행된 우선주)
* **B (Bond):** 채권(Bond)의 성격을 가진 우선주를 뜻합니다. 회사가 적자가 나더라도 정해진 최저 배당률을 보장해 주거나, 올해 못 준 배당금을 내년에 누적해서 주는 등 **배당 보장 요건이 더 강화된 신형 우선주**입니다.

### 📌 어떤 사람에게 적합할까요?
* 회사의 주주총회나 경영에는 관심이 없고, **오직 은행 예적금보다 높은 배당 수익이나 안정적인 현금 흐름을 원하시는 투자자**에게는 보통주보다 가격이 저렴해 배당수익률이 더 높은 **우선주 투자**가 매력적인 선택이 될 수 있습니다.

# 금융기관별 대출 상품, 이자 계산식 및 상환 가이드북

본 가이드북은 은행, 카드사, 기타 금융기관의 주요 대출 상품별 특징과 이자 계산 방식, 그리고 중도상환 및 만기 상환 시 유의해야 할 핵심 금융 정보를 집약한 보고서입니다.

---

## 1. 금융기관별 주요 대출 상품 비교

### 1.1 제1금융권 (시중은행, 인터넷전문은행)
* **주요 상품**: 신용대출, 주택담보대출, 전세자금대출, 마이너스통장(한도대출)
* **특징**: 금리가 가장 낮고 한도가 안정적이나, 심사 기준(신용점수, DSR 등)이 엄격합니다.
* **마이너스통장 특이사항**: 일반 대출과 달리 부여된 한도 내에서 쓴 금액과 기간에 대해서만 이자가 복리로 발생합니다.

### 1.2 제2금융권 (카드사, 캐피탈, 저축은행)
* **주요 상품**: 
    * **단기카드대출 (현금서비스)**: 소액 단기 급전 목적, 다음 달 결제일에 상환.
    * **장기카드대출 (카드론)**: 수개월~수개년에 걸쳐 분할 상환하는 신용대출 상품.
    * **신용대출 및 신차 할보**: 저축은행 및 캐피탈사의 중·고금리 대출.
* **특징**: 은행 대비 심사가 유연하고 실행이 빠르나, 금리가 상대적으로 높으며 신용점수 하락 폭이 은행보다 클 수 있습니다.

### 1.3 기타 기관 (정책금융, 대부업 등)
* **정책 서민금융**: 서민금융진흥원(햇살론), 주택금융공사(디딤돌·보금자리론) 등 저소득·저신용자 또는 무주택자를 위한 우대 금리 상품.
* **등록대부업**: 법정 최고금리(연 20%) 이내에서 실행되는 최후순위 대출.

---

## 2. 이자율 계산 방식 및 공식

대출 이자는 기본적으로 **'빌린 원금 x 연이자율 x 사용일수 ÷ 365(윤년은 366)'**의 일할 계산을 원칙으로 합니다.

### 2.1 일반 신용/담보대출 및 카드사 대출 (일할 계산)
대출을 받은 날부터 상환하기 전날까지의 일수를 계산하여 이자를 부과합니다. (선결제 시 이자가 줄어드는 원리)

$$\text{이 자} = \text{대출 원금} \times \text{연 이자율} \times \frac{\text{대출 이용일수}}{365}$$

### 2.2 마이너스통장 (한도대출) 이자 계산
매일 마감 잔액(최고 잔액 적용 공식 포함) 기준 사용한 금액에 대해 일할 계산된 이자가 한 달에 한 번 원금에 가산(대출 원장 반영)됩니다. 이 때문에 이자에 이자가 붙는 **복리 효과**가 발생합니다.

$$\text{일일 이자} = \text{당일 마이너스 사용 잔액} \times \frac{\text{연 이자율}}{365}$$

---

## 3. 대출 상환 방식 종류

어떤 상환 방식을 선택하느냐에 따라 총지출되는 이자의 합계가 크게 달라집니다.

```
[상환 방식별 총 이자 부담 크기 비교]
만기일시상환 > 원금균등상환 > 원리금균등상환 (초기 잔액이 느리게 줄어들수록 이자가 많음)
```

1.  **원리금균등분할상환**: 매달 [원금 + 이자]의 합계 금액을 동일하게 맞추어 납부하는 방식입니다. 초기에는 이자의 비중이 높고 갈수록 원금 상환 비중이 커집니다. 자금 계획 수립에 유리합니다.
2.  **원금균등분할상환**: 매달 동일한 액수의 '원금'을 갚고, 남은 잔액에 대한 이자를 더해 내는 방식입니다. 매달 총 결제 금액이 줄어들며, 세 가지 방식 중 **총이자가 가장 적습니다.**
3.  **만기일시상환**: 대출 기간 동안에는 이자만 매달 내다가, 만기일에 원금 전액을 한 번에 갚는 방식입니다. 매월 부담은 적으나 **총이자 부담이 가장 큽니다.**

---

## 4. 중도상환 및 선결제(조기상환) 핵심 포인트

* **중도상환 수수료 여부**:
    * **제1금융권(은행)**: 보통 대출 실행 후 3년 이내에 갚으면 0.5% ~ 1.5% 수준의 중도상환 수수료가 일수 계산되어 부과됩니다. (정책 자금이나 일부 상품은 면제되기도 함)
    * **카드사 단기대출(현금서비스)/카드론**: 대부분 **중도상환 수수료가 없습니다.** 따라서 자금이 생기는 즉시 선결제하는 것이 무조건 유리합니다.
* **신용점수 관리**: 단기·장기 카드대출의 잔액을 조기에 상환하여 없애면, 보유 대출 건수와 기대출 금액이 감소하여 신용평가사(NICE, KCB)의 신용점수 회복에 매우 긍정적인 영향을 미칩니다.
